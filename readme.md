# git commands
**git add [file]** # adds a file in it's current state to the staging area/ to next commit<br />
**git status** # shows modified files in working direcotry, staged for next commit<br />
**git reset [file]**  # unstage a file while retaing the changes in working dir<br />
**git branch [branch-name]** # lists branches with * beside working branch, if we include a branch name we instead create a new brenach at current commit <br />
**git init** # initialize an existing directory as a Git repository<br />
**git remote add [alias] [url]** # add a git url as an alias(generally how we'll link a local repo to a remote one)<br />
**git log -p** # show commit history of current active branch -p argument will show changes in docs between commits<br />
**git diff -- [file]** # diff of what is changed but not staged, -- [file] targets a specific file<br />
**git checkout -b [branch name]** # changes to specified branch, if -b option is added it will created the specified branch and switch to it<br/ >
